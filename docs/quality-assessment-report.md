## 质量风险评估

### 高风险项

1. **Physics 模块零覆盖率**
   - 风险等级：高
   - 影响范围：`physics/` 下 8 个文件约 975 行代码全部未测试
   - 风险描述：物理仿真模块（空气动力学、刹车、差速器、悬挂、轮胎模型等）完全没有测试覆盖，若该模块被集成到主流程中，存在严重质量隐患
   - 建议措施：①确认 physics 模块是否属于当前版本范围内的功能；②若属于范围外，应在文档中明确标注为未集成模块；③若属于范围内，必须优先补充单元测试

2. **API 层覆盖率偏低**
   - 风险等级：高
   - 影响范围：`api/routes.py`（60.18%）和 `api/ws.py`（50.53%）
   - 风险描述：REST API 和 WebSocket 事件处理的错误路径、边缘 case 大量未覆盖，可能导致生产环境异常处理不当
   - 建议措施：①补充 API 路由的错误场景测试（无效参数、权限校验、异常处理）；②补充 WebSocket 连接管理测试（断线重连、异常关闭、消息格式错误）

### 中风险项

1. **前端 UI 任务未验证**
   - 风险等级：中
   - 影响范围：T8 任务（中文界面、SVG 赛道图、弯道热区、反馈面板）
   - 风险描述：前端 UI 功能仅有后端 API 测试覆盖，缺乏前端交互逻辑的自动化验证
   - 建议措施：①补充前端 JavaScript 逻辑的单元测试；②进行人工 UI 走查验证

2. **打包 CI/CD 任务未验证**
   - 风险等级：中
   - 影响范围：T9 任务（Nuitka 编译、GitHub Actions 冒烟、Release 发布）
   - 风险描述：打包和发布流程未在本次评估中验证，可能存在编译失败或冒烟测试不通过的风险
   - 建议措施：①在 GitHub Actions 环境中执行完整 CI/CD 流程验证；②确认 Nuitka 编译产出和冒烟测试结果

3. **PyTorch 依赖导致测试跳过**
   - 风险等级：中
   - 影响范围：`tests/test_nn_model.py` 中 4 条测试
   - 风险描述：NN 模型相关测试因 PyTorch 不可用而被跳过，虽然 `nn_model.py` 代码覆盖率达 100%，但跳过的测试可能涉及模型推理逻辑的验证
   - 建议措施：①在 CI 环境中安装 PyTorch 以启用跳过的测试；②或确认跳过的测试逻辑已被其他测试覆盖

### 低风险项

1. **Engine 模块部分文件覆盖率低于 90%**
   - 风险等级：低
   - 影响范围：`engine/engine.py`（85.50%）、`engine/diagnostic.py`（86.08%）
   - 风险描述：虽然 Engine 模块整体覆盖率达 94.38%（超过 90% 门槛），但 engine.py 和 diagnostic.py 个别文件略低
   - 建议措施：补充这两个文件中未覆盖的分支测试（主要集中在错误处理和边缘 case 路径）

2. **Telemetry recorder.py 覆盖率偏低**
   - 风险等级：低
   - 影响范围：`telemetry/recorder.py`（81.75%）
   - 风险描述：录制器模块有 45 行未覆盖，涉及录制控制和数据持久化的部分逻辑
   - 建议措施：补充录制器的完整流程测试

3. **第三方库弃用警告**
   - 风险等级：低
   - 影响范围：Starlette/httpx 弃用警告
   - 风险描述：TestClient 使用的 httpx 与 Starlette 存在弃用警告，未来版本可能不兼容
   - 建议措施：关注 Starlette/httpx 版本更新，适时迁移到 httpx2
