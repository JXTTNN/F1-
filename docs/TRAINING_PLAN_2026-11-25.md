# 用现有遥测数据训练模型：方案

数据：`data/f1_2026/train/`（21 站 Race 全量干净圈，19,459 圈 / 314,891 条逐弯样本 / 25 位车手）
切分：`splits.json`（train 15 站 / val 3 站 / test 3 站，同场不跨 split）
下文所有指标都是**按分站留出**实测得到，脚本见文末。

---

## 0. 一句话结论

这套数据**能做出可靠的「已入库赛道逐弯基准库」，但做不出能预测新车道的模型**。
所以训练目标必须从"预测圈速"改成"给出基准 + 估计同场内的相对差异"，否则一定失败。

---

## 1. 先看清数据能支撑什么

### 1.1 逐弯任务（目标：弯时占圈速比，中位 0.0476）

| 模型 | 已见赛道 R² / MAE | 未见赛道(val) | 未见赛道(test) |
|---|---|---|---|
| L0 赛道×弯 中位数（查表） | **0.9683** / 0.0030 | 0.0577 / 0.0244 | -0.0784 / 0.0265 |
| L1 全局岭回归（带 pair 身份，255 维） | 0.9682 / 0.0032 | -0.1058 / 0.0290 | -0.0815 / 0.0268 |
| L1b 仅工况特征（无身份） | 0.0457 / 0.0305 | -0.5874 / 0.0299 | -0.1008 / 0.0274 |
| L2 残差建模（扣掉基准再学工况） | 0.0028 / 0.0031 | -0.0025 / 0.0242 | -0.1368 / 0.0265 |

训练站 pair 数 241，全量 344——即验证/测试站的弯在训练时从未见过，one-hot 全为 0。

**三条硬结论：**

1. **L1 没有打赢查表。** 已见站 0.9682 vs 0.9683，学到的部分≈0。之前报的"ridge R²=0.9747"就是这个口径，属"已见赛道"，不是泛化成绩。
2. **跨赛道几乎不可迁移。** 未见站 R² 掉到 0.06 / -0.08，MAE 0.024–0.026，相对误差约 50%。
3. **工况特征几乎没有线性信号。** 单独用胎/温度/天气只能解释 4.6%，扣掉基准做残差后只剩 0.3%。

圈速闭合校验（把逐弯预测占比 × 圈速累加，与实测圈速比）：已见站中位误差 5.67%，未见站 18.5%。
→ **这个代理模型不能用来还原圈速**，只能当逐弯相对参考。

### 1.2 整圈配速任务（19,459 圈）

| 模型 | 已见站 R² / MAE | 未见站(val) | 未见站(test) |
|---|---|---|---|
| L0 赛道中位数 | 0.9358 / 1.63 s | -6.13 / 16.75 s* | -0.83 / 6.33 s* |
| L1 岭回归（赛道画像+胎+温度+车手） | 0.7597 / 3.99 s | -1.95 / 9.59 s | 0.1058 / 5.84 s |

\* 未见站没有"该赛道中位数"可用，回退到全局中位数，所以这一列只说明"查表不能跨站"，不代表模型水平。

**结论：** 圈速同样不可跨站预测（test R²≈0.11，MAE 5.8 s）。调教优化需要的是 0.1% 量级精度，差两个数量级。

### 1.3 为什么？——残差里到底有多少信号

在已见站上扣掉"赛道×弯"基准后，做单因素方差分解（R² 上限 = 组间可解释方差）：

| 目标口径 | 残差 std | 车手上限 | 胎种上限 | 弯型上限 |
|---|---|---|---|---|
| 绝对弯时（秒） | 0.6468 s | 0.0100 | 0.0246 | 0.0001 |
| 弯时占圈速比 | — | 0.0001 | 0.0002 | — |

两个关键事实：

- **占比口径把性能差异归一化掉了。** 车手之间只差 0.01% 的方差——快车手是"每个弯等比例快"，不是"某个弯特别快"。所以用占比当目标，永远学不到车手/车/胎的性能。
- **单圈单弯观测噪声极大。** 残差 std 0.65 s，而车手效应只占 1%。逐样本回归必然被噪声淹没，**必须先聚合**。

## 2. 训练前必须修的 6 个数据问题

不修就会学歪，且都不难修。

| # | 问题 | 实测 | 处理 |
|---|---|---|---|
| 1 | `max_lateral_g` / `max_long_g` **不是 g，是原始加速度** | 中位 37.4 / 44.3；÷9.81 = 3.8 g / 4.5 g 才是真实量级；p99 达 134 | 统一 ÷9.81，再按 6 g 截尾 |
| 2 | `max_long_g` 有 0 值 | min = 0，p01 = 0 | 视为缺失，按该弯中位数填补（占比 <1%） |
| 3 | `tyre_life` 有字符串 `"None"` | 239 行 | 转缺失标记，不能直接 `float()` |
| 4 | `drs_pct` 是死特征 | 314,891 行**全为 0** | 剔除 |
| 5 | 湿圈是单场混淆 | 506 圈中 452 圈来自圣保罗，sakhir 53、montreal 1 | 不建湿滑模型；湿圈权重 0.5，圣保罗单独留出报告 |
| 6 | 逐弯样本缺圈级上下文 | `corner_samples` 无 `tyre_life`/`stint`/`position` | 与 `laps_clean` 按 (race, driver, lap) join |

另：胎种分布 hard 7,341 / medium 6,208 / soft 5,345 / inter 506 / unknown 59；新旧胎 16,900 / 2,559。

## 3. 四条训练轨道

### 轨道 A：逐弯基准库（主交付物，不靠 ML）

**做什么**：每站每弯给出一组基准量——弯时、弯时占比、入口/最低/出口速度、刹车占比、油门全开占比、G 值 p10/p50/p90。

**怎么做**：经验贝叶斯收缩，而不是直接取中位数

```
shrunk = (n / (n + k)) × 该弯中位数  +  (k / (n + k)) × 该弯型中位数      k ≈ 20
```

样本少的弯（如 monaco 某些弯只有 20 圈）向弯型均值收缩，避免单弯噪声。

**验收**：已见站 R² ≥ 0.95（现 0.968 已达标）；未见站只检查"基准是否稳定"，**不要求 R²**。
**用途**：替换引擎里 `importance = 120 / 参考速度` 这条纯经验启发式，给教练提示提供"该弯基准值"。

### 轨道 B：聚合后的相对模型（核心增量）

**关键纪律：先聚合，再建模。** 逐样本信噪比不够（残差 0.65 s，车手效应 1%）。

- 聚合键：`(track, corner, driver, stint)`，或 `(track, corner, tyre_class, tyre_life_bucket)`
- 每组要求 ≥10 圈重复观测；不足的组合并到上一级
- 目标：**绝对弯时**相对该弯基准的偏差（秒），不要用占比
- 特征：胎龄、新旧胎、stint 序号、赛道/空气温度、干湿、车手

**验收**：聚合后 val R² ≥ 0.30 才继续投入；达不到就降级为"仅描述统计"（分组均值 + 置信区间），不做预测模型。

### 轨道 C：轮胎退化

- 目标：同一 stint 内圈速随 `tyre_life` 的斜率，按弯型分解（慢弯/中速弯/快弯退化不同）
- 方法：每个 stint 单独线性拟合 → 按胎种×弯型分层汇总 → 报告斜率与 95% CI
- 验收：斜率方向一致率 ≥80%，且分层斜率的 CI 不含 0
- 用途：给"胎龄→圈速"提供真实约束，替代拍脑袋的退化系数

### 轨道 D：调教→圈速（899 条，独立任务）

```bash
python scripts/train_real_lap_model.py \
  --source data/f1_2026/train/setups_f1_26.jsonl \
  --min-per-track 10 --folds 5
```

- 定位：**排序/方向**，不做精确预测（899 条撑不起精确回归）
- 验收：`skill = 1 - MAE / 赛道均值基线 > 0.15` 才允许它覆盖物理方向（C 矩阵）；否则只用于候选排序
- 红线：不与真实遥测圈速配对（游戏口径 ≠ 真实口径）

## 4. 切分与验收协议

**三套切分都要报，只报一套不算数：**

| 切分 | 做法 | 回答什么问题 |
|---|---|---|
| 分站留出 | `splits.json` 15/3/3 | 能不能用到新赛道 |
| 车手留出 | 25 人里留 5 人完全不进训练 | 能不能用到新车手 |
| 时间留出 | 按赛历顺序，前 15 站训、后 6 站测 | 最贴近真实上线场景 |

**禁止**：随机按圈切分。随机切会得到 R²=0.97 的假成绩（同场同弯泄漏）。

## 5. 执行顺序与停止条件

| 阶段 | 内容 | 工作量 | 停止/继续判据 |
|---|---|---|---|
| P0 | 数据体检 + 6 项修复 + join | 0.5 天 | 修完必须重跑一遍基线，确认指标不变差 |
| A | 收缩估计建基准库 + 抽样人工核对 3 个弯 | 1 天 | 已见站 R² ≥0.95 → 交付 |
| B | 聚合 + 相对模型 | 1–2 天 | 聚合后 val R² ≥0.30 → 继续；否则降级为描述统计 |
| C | 轮胎退化分层拟合 | 1 天 | 方向一致率 ≥80% → 入库 |
| D | 调教模型 + 接入引擎验证 | 1 天 | skill >0.15 → 允许覆盖物理方向 |

总计约 4–5 天。A 和 C 是稳的，B 有可能拿不到可用模型（要提前接受这个结果）。

---

## 6. 明确不做

1. **不做跨赛道预测模型**——实测 R²≈0，投入产出不成立。
2. **不逐样本回归敏感度**——残差 0.65 s、效应 1%，必被噪声淹没。
3. **不把游戏调教与真实圈速配对**——公开真实遥测不含车队调教，899 条是 F1 26 游戏口径。
4. **不用随机切分报成绩**。
5. **不用 `drs_pct`、不把 m/s² 当 g**。
