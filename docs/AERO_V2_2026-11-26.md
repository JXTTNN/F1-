# 气动模型与优化器预算（2026-11-26）

## 一句话结论

引入 2026 气动特性后，**真正的提升来自优化器预算而不是模型**：在标尺完全不变的前提下，
42 组端到端平均收益 **−140.6 → −235.0 ms（+67%）**、中位 **−106.8 → −249.2 ms（+131%）**，
"比默认更慢"的站点 **3 → 0**。

新气动标尺训出的 NN 没过仓库门禁（局部 MAE 482 ms），因此**气动模型以候选方式入库、默认关闭**。

---

## 1. 为什么要动物理模型

上一轮诊断出三件事：重要度只差 0.004、优化器对步长是刀尖响应、spielberg/spa 两版模型
都给出"比默认更慢"的建议。根因是旧物理把气动写成线性项：

- `front_ride_height / rear_ride_height → A: ±0.035`，即**越低越快、没有下限**；
- 翼角只进 `A`，后翼还额外给 `M`，导致"加尾翼永远更快"；
- 阻力只有 `C_LIN·df + C_IND·df²`，与下压力脱钩；
- 没有气动平衡，没有失速。

实测旧模型在 Monza 把车高降到 −1.0 会给出 **−685 ms**，这在真实 F1 里是失速撞地板的量级。

## 2. 新增的气动模型（`scripts/f1_aero.py`）

| 特性 | 实现 | 依据 |
|---|---|---|
| 地效曲线 | 峰值在归一化 −0.30，两侧二次衰减；−0.78 以下进入失速，下压力最多掉 45% | 2026 规则取消地效通道、平底+加长扩散器，曲线比 2022–25 平缓但仍有峰值与失速 |
| 气动平衡 | 前翼↑前移、后翼↑后移；目标份额随赛道高速弯占比变化，偏差按圈速罚时 | 高速弯需要更前移的平衡；街道赛偏后轴稳定 |
| 诱导阻力 | 翼面 `k=0.13`、底板 `k=0.06` 分开算（底板 L/D 更高） | CD = CD0 + k·CL² |
| 主动气动 | 直道 X-mode 把翼角阻力折减到 65% | 2026 用主动气动取代 DRS |
| 平台稳定性 | 软悬挂 + 低车高 → 高速弯失稳罚 | 制动俯冲改变离地间隙 |
| 量级标定 | 1% CL ≈ 0.02 s/圈；前后翼加满 0.2–0.6 s；车高 −0.4 约 0.03–0.25 s | 公开工程量级 |

### 验证（`scripts/validate_aero.py`，5 项全过）

| 赛道 | 前后翼加满 | 车高 −0.4 | 车高 −1.0（失速） |
|---|---|---|---|
| monza | +1.5 ms | −80.1 ms | **+841.5 ms** |
| spa | +16.6 ms | −43.0 ms | **+1060.9 ms** |
| monaco | −52.2 ms | −119.3 ms | **+736.2 ms** |
| silverstone | −35.7 ms | −105.9 ms | **+1020.3 ms** |

车高扫描出现**内点最优（−0.4）**、再低就失速，这正是旧模型缺的结构。产物：
`docs/reports/aero_validation.json`。

## 3. 用新标尺重训 NN：没过门禁，不上线

- 训练：val MAE 89.03 ms / R² 0.9945；局部（<300 ms）40.93 ms
- 但仓库自己的评测脚本（围绕物理最优点采样）给出：**局部 MAE 482.86 ms、成对排序 0.577、
  方向一致率 0.663 → 门禁 FAIL**（门槛 120 ms / 0.75 / 0.8）

原因是新气动让最优点周围的景观变陡（失速边界），48×32 的纯标准库 MLP 容量不够。
在它通过门禁之前，`AERO_V2` 保持默认关闭；标尺与训练代码都已入库，随时可复跑。

端到端也印证了这一点：新 NN 在新标尺下 −384.75 ms，旧 NN −385.22 ms，**没有差异**
（3 胜 2 负 37 平）。

## 4. 真正的瓶颈：优化器预算

诊断时发现 `sim_optimizer` 的信赖上限把优化器锁死了：

| 常数 | 旧值 | 新值 | 含义 |
|---|---|---|---|
| `_MAX_TOTAL_GAIN_S` | 0.120 | **0.250** | 累计记账收益到顶就停 |
| `_MAX_MOVES` | 3 | **5** | 最多接受几步 |
| `_MAX_STEP_GAIN_S` | 0.080 | **0.100** | 单步记账上限 |
| `_GRID` | 0.25 | **0.28** | 坐标上升步长 |
| `_OBJ_BUDGET` | 0.08 | **0.12** | 目标代价预算 |

三个预算档位的实测（6 个问题赛道，物理标尺不变）：

| 预算 | monaco | monza | spa | spielberg | las_vegas | miami | 平均 |
|---|---|---|---|---|---|---|---|
| 120/3/80（旧） | −129.5 | −90.9 | **+51.4** | **+32.7** | **+5.9** | −26.5 | −26.1 |
| 250/5/100（新） | −297.0 | −281.2 | −209.2 | −139.3 | −221.6 | −93.0 | **−206.9** |
| 400/8/150（过激） | −328.8 | −329.4 | −520.6 | −213.6 | −309.5 | −329.8 | −338.6 |

旧预算下三个赛道**越优化越慢**；放宽后全部转正。400 档虽然更高，但已超出可信量级
（全套平均 −767 ms），故不采纳。

### 上线口径（旧标尺 + 旧模型 + 新预算，42 组）

| 指标 | 旧预算 | 新预算 | 变化 |
|---|---|---|---|
| 平均物理收益 | −140.6 ms | **−235.0 ms** | **+67%** |
| 中位物理收益 | −106.8 ms | **−249.2 ms** | **+131%** |
| 比默认更慢 | 3 / 42 | **0 / 42** | 清零 |
| 单次耗时 | 104.1 ms | ≈76 ms | 仍快于上一轮 |

## 5. 决策与下一轮

- 上线：`sim_optimizer` 新预算（唯一行为变更），生产 `setup_sim_nn.json` 保持原版。
- 入库但默认关闭：`f1_aero` 气动模型 + `AERO_V2` 开关 + 验证脚本 + 数据构建分支。
- 下一轮 P0：把 NN 容量提到 64×48 或改用分段线性拟合，让气动标尺通过 120 ms 门禁；
  通过后切 `AERO_V2=True` 重训，再跑一次 42 组 A/B。
- 湿地方程仍未建模：spielberg 湿地的 +430 ms 是干地标尺评湿地建议的产物，
  在补湿地方程前，湿地结论只作参考。
