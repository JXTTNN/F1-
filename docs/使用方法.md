## 安装

### 方式一: 下载 EXE (推荐)

从 [Releases](https://github.com/JXTTNN/F1-/releases) 下载, 双击运行, 无需 Python.

### 方式二: 源码安装

```bash
git clone https://github.com/JXTTNN/F1-.git
cd F1-
pip install -e ".[dev]"
```

## 命令一览

```
f1opt feedback    车手反馈 (问问题 → 分析遥测 → 给建议)
f1opt search      调校搜索 (差分进化 / 贝叶斯)
f1opt bayesian    贝叶斯优化
f1opt predict     圈速预测
f1opt train       训练性能模型
f1opt serve       启动 API 服务
f1opt template    生成车手反馈模板
f1opt tracks      查看赛道信息
f1opt setup       查看默认调校 / 验证调校
f1opt validate    模型验证
```

每个命令都支持 `--json` 输出, 方便脚本调用.

## 车手反馈

### 三级精度

系统自动识别你的问题属于哪个级别:

| 级别 | 你问的 | 示例 |
|---|---|---|
| **弯道** | 具体弯道 | "T1 入弯总推头" |
| **扇区** | 某一段 | "S2 连续弯指向性差" |
| **整体** | 整圈 | "还能快多少?" |

### 弯道级

```bash
f1opt feedback --track suzuka --question "T1 入弯总推头怎么办?"
f1opt feedback --track suzuka --question "T130R 出弯速度上不去"
f1opt feedback --track monza --question "出弯时车尾总往外甩"
```

### 扇区级

```bash
f1opt feedback --track suzuka --question "S2 连续弯那段指向性太差"
f1opt feedback --track monza --question "S3 高速段车身不稳"
```

### 整体级

```bash
f1opt feedback --track bahrain --question "圈速能再快多少?"
f1opt feedback --track spa --question "轮胎温度左边比右边高很多"
f1opt feedback --track suzuka --question "ERS 怎么部署最快?"
```

### 多轮对话

同一个 `--session-id` 会记住上下文:

```bash
# 第一轮
f1opt feedback --track suzuka --question "T1 推头怎么办?" --session-id lap1

# 第二轮 (记住上文)
f1opt feedback --track suzuka --question "改了前翼还是推, 怎么办?" --session-id lap1
```

### 查看所有示例

```bash
f1opt feedback --list-examples
```

## 调校搜索

### 差分进化 (默认)

```bash
f1opt search --track suzuka --iterations 100
```

### 贝叶斯优化

```bash
f1opt bayesian --track monza --iterations 15 --acquisition ei
```

采集函数可选: `ei` (期望提升) / `ucb` (上置信界) / `pi` (概率提升).

### 多目标 (圈速 vs 轮胎磨损)

```bash
f1opt search --track spa --iterations 200 --tire-wear-weight 0.5
```

`--tire-wear-weight` 越大, 越偏向保胎策略.

### 输出 JSON

```bash
f1opt search --track suzuka --iterations 50 --json > result.json
```

```bash
  "rear_tyre_pressure": 21,
  "front_camber": -3.0,
  "rear_camber": -1.5,
  "front_toe": 0.05,
  "rear_toe": 0.15,

  "rear_ride_height": 5,
  "front_brake_bias": 50,
  "brake_pressure": 90,
  "fuel_load": 30

```

查看默认调校:

```bash
f1opt setup default --json
```

```bash
f1opt setup validate --setup-json '{"front_wing":30,"rear_wing":25,...}'
```

## 实时遥测

### 完整工作流

```
1. f1opt serve                    启动 API 服务
2. 开 F1 25/26 游戏                在设置里打开 UDP 遥测 (端口 20777)
3. 进赛道跑圈                      系统自动采集 60Hz 数据
4. 跑完后 Ctrl+C 停止              LLM 自动启动分析
5. 查看报告                        浏览器打开 http://127.0.0.1:8000
```

### 启动服务

```bash
f1opt serve                          # 默认 127.0.0.1:8000
f1opt serve --host 0.0.0.0 --port 9000   # 自定义地址
f1opt serve --extended                # 启用扩展 API
```

### API 接口

| 接口 | 用途 |
|---|---|
| `GET /api/health` | 健康检查 |
| `GET /api/tracks` | 赛道列表 |
| `GET /api/setup/default` | 默认调校 |
| `GET /api/templates` | 反馈模板 |
| `POST /api/feedback/analyze` | 分析反馈 |
| `POST /api/llm/preload` | 加载 LLM (跑完游戏后调用) |
| `POST /api/llm/unload` | 释放 LLM 内存 |
| `WS /api/ws/telemetry` | WebSocket 实时遥测流 |

完整 API 文档: 启动 `f1opt serve` 后访问 `http://127.0.0.1:8000/docs`

## 反馈模板

给车手提供结构化模板, 跑完圈后填写, 帮助 LLM 更准确分析.

### 按组生成

```bash
f1opt template --group corner    # 弯道级模板 (推头/过度转向/刹车/牵引力)
f1opt template --group sector    # 扇区级模板 (平衡/轮胎)
f1opt template --group overall   # 整体级模板 (总评/调校/ERS/对比)
f1opt template --group all       # 全部 10 个模板
```

### 指定单个模板

```bash
f1opt template --id corner_understeer    # 弯道推头模板
f1opt template --id overall_setup        # 整体调校模板
```

### 语言

```bash
f1opt template --group all --lang zh    # 中文 (默认)
f1opt template --group all --lang en    # 英文
```

## 车手风格

反馈和搜索都支持车手风格预设:

| 风格 | 特点 |
|---|---|
| `aggressive` | 激进 — 晚刹车, 强力 ERS |
| `conservative` | 保守 — 保胎优先, 保守 ERS |
| `balanced` | 平衡 — 综合考量 |
| `smooth` | 平顺 — 最小化输入扰动 |
| `late_braker` | 超晚刹车 — 极端入弯激进 |

```bash
f1opt feedback --track suzuka --question "T1 推头" --style aggressive
f1opt feedback --track suzuka --question "T1 推头" --driver-style conservative
```

`--style` 比 `--driver-style` 更细化, 同时使用时 `--style` 优先.

## LLM 配置

LLM 只在游戏跑完后才加载, 游戏期间不占内存.

### 配置方法

复制 `.env.example` 为 `.env`, 修改:

```ini
F1OPT_LLM_BACKEND=none          # none / openai / local
F1OPT_LLM_API_KEY=sk-xxx        # API 密钥
F1OPT_LLM_MODEL=gpt-4o-mini     # 模型名称
```

或用环境变量:

```bash
export F1OPT_LLM_BACKEND=openai
export F1OPT_LLM_API_KEY=sk-xxx
f1opt serve
```

### 手动控制 LLM 生命周期

```bash
# 跑完游戏后, 加载 LLM
curl -X POST http://127.0.0.1:8000/api/llm/preload

# 分析完, 释放内存
curl -X POST http://127.0.0.1:8000/api/llm/unload
```

## 常见问题

### Q: 找不到赛道 ID?

```bash
f1opt tracks list
```

### Q: 调校参数有哪些?

```bash
f1opt setup default --json
```

共 19 个参数: 前翼、后翼、油门差速器、收油差速器、前后悬挂、前后防倾杆、前后胎压、前后外倾角、前后束角、前后车身高度、制动偏置、制动压力、燃油载荷.

### Q: 游戏里遥测怎么开?

F1 25/26 游戏设置 → 遥测设置:
- UDP 格式: 2024 规范
- UDP 端口: 20777
- UDP 发送速率: 60Hz
- 向前发送: 开启

### Q: EXE 在 Windows 上被杀毒软件拦截?

这是 PyInstaller 打包的常见问题. 把 `f1opt` 文件夹加入杀毒白名单, 或用源码方式运行.

### Q: 不想用 LLM, 只用规则反馈?

不设置 `F1OPT_LLM_BACKEND` (保持 `none`) 即可, 系统会给出基于遥测数据的规则反馈.

### Q: 多轮对话上限?

同一 `--session-id` 最多记住最近 20 轮对话, 超出自动滚动.
